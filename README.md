# /beta-fleet

A Claude Code skill that sends five first-time users through your app before launch, fixes what they hit, and reruns them to prove it. Built on [this tweet](https://x.com/RoundtableSpace/status/2111717667228770611).

```bash
git clone https://github.com/seanblundin/beta-fleet.git ~/.claude/skills/beta-fleet
```

Then type `/beta-fleet` in your app's folder. You'll need a browser your Claude can drive, such as Playwright MCP.
